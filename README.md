# System Seller

Sistema de gestão de pedidos para centralizar Shopee e Mercado Livre.

## Versão inicial

- Painel de pedidos com busca e filtros por status
- Priorização por prazo de envio
- Detalhe do pedido e avanço do fluxo: novo → separar → embalar → enviado
- Estrutura de integração para Shopee e Mercado Livre
- Indicadores de pedidos, envios e faturamento

As credenciais oficiais dos marketplaces devem ser configuradas antes da sincronização automática de pedidos e etiquetas.
